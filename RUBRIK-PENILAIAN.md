# Daftar Periksa Rubrik Penilaian — EduGen AI

Gunakan daftar ini ketika mengecek website sebelum presentasi atau pengumpulan.

## 1. Struktur dan kelengkapan website
- [x] Beranda/pengantar.
- [x] Bagian rangkuman materi.
- [x] Bagian kuis/evaluasi.
- [x] Bagian informasi proyek akhir.
- [x] Navigasi desktop dan menu ponsel mengarah ke bagian yang sesuai.

## 2. Kualitas desain UI/UX
- [x] Identitas visual bergaya IT dengan tema gelap, aksen neon, panel, dan elemen seperti terminal.
- [x] Tema gelap dan terang.
- [x] Tata letak responsif untuk desktop dan ponsel.
- [x] Kontras, label kontrol, fokus keyboard, dan tombol dengan status yang jelas.
- [x] Animasi dapat dikurangi mengikuti preferensi reduced motion perangkat.

## 3. Isi dan akurasi materi
- [x] Enam modul memiliki penjelasan ringkas, poin-poin, contoh, dan pesan utama.
- [x] Cakupan materi: konsep AI generatif, analisis kebutuhan, pengembangan media, implementasi, evaluasi, serta etika.
- [x] Halaman menautkan rujukan UNESCO tentang Generative AI dalam pendidikan dan kompetensi AI siswa, serta rujukan NIST tentang risiko Generative AI.
- [ ] Sebelum dinilai, pemilik tugas tetap perlu membandingkan isi dengan soal/instruksi guru, kurikulum, dan sumber belajar kelas.

## 4. Fungsionalitas
- [x] Pencarian mencakup judul, ringkasan, dan isi modul.
- [x] Filter semua/belum selesai/selesai.
- [x] Dialog materi, navigasi modul sebelumnya/berikutnya, dan status selesai yang dapat dibatalkan.
- [x] Progres belajar tersimpan lokal dan dapat direset.
- [x] Kuis 10 soal memberi umpan balik dan pembahasan, menghitung skor, meninjau jawaban, dan dapat diulang.
- [x] Riwayat skor tersimpan lokal.
- [x] Tema, menu ponsel, indikator baca, notifikasi, dan tombol kembali ke atas.

## 5. Kreativitas dan inovasi
- [x] Tampilan terminal bertema IT.
- [x] Pengalaman belajar menggabungkan materi, pencarian, progres, kuis, dan riwayat skor.
- [x] Rujukan dan catatan verifikasi ditempatkan pada bagian proyek akhir.

## 6. Dokumentasi dan presentasi
- [x] Petunjuk instalasi/penggunaan ada di README.
- [x] Tujuan pembelajaran, struktur file, fitur, batasan penyimpanan lokal, dan urutan demonstrasi dijelaskan.

## 7. Kerapian kode
- [x] HTML, CSS, dan JavaScript dipisahkan ke file masing-masing.
- [x] Fungsi diberi nama yang menggambarkan tugasnya dan data konten dipisahkan dari logika tampilan.
- [x] Nilai dari konten dinamis di-escape sebelum dimasukkan ke HTML.
- [x] Penanganan penyimpanan lokal dibuat defensif.
- [x] Pemeriksaan sintaks JavaScript menggunakan `node --check script.js`.

## Rujukan yang ditampilkan di website

1. UNESCO (2023), *Guidance for generative AI in education and research*: https://www.unesco.org/en/articles/guidance-generative-ai-education-and-research
2. UNESCO (2024), *AI competency framework for students*: https://www.unesco.org/en/articles/ai-competency-framework-students
3. NIST (2024), *Artificial Intelligence Risk Management Framework: Generative Artificial Intelligence Profile*: https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence
