# EduGen AI — Website Rangkuman Materi Interaktif

**Topik:** Generative AI untuk pengembangan media pembelajaran  
**Jenis produk:** Website edukasi responsif  
**Teknologi:** HTML, CSS, dan JavaScript murni (tanpa framework)

## Cara menjalankan

1. Ekstrak ZIP ke satu folder.
2. Pastikan `index.html`, `style.css`, dan `script.js` tetap berada di folder yang sama.
3. Buka `index.html` menggunakan Chrome, Edge, atau Firefox.
4. Jika ingin mengedit, buka folder tersebut di Visual Studio Code dan jalankan `index.html` di browser. Ekstensi Live Server boleh digunakan, tetapi tidak wajib.

Website tidak membutuhkan backend atau database. Font Google digunakan sebagai peningkatan tampilan; jika internet tidak tersedia, font sistem akan digunakan. Progres dan riwayat kuis disimpan secara lokal di browser/perangkat yang sama, bukan ke server.

## Fitur utama

- Beranda dengan pengantar, statistik, dan navigasi ke bagian penting.
- Enam modul materi dari konsep dasar sampai etika dan tanggung jawab AI.
- Pencarian materi berdasarkan judul, ringkasan, dan isi modul.
- Filter modul: semua, belum selesai, dan selesai.
- Dialog baca materi dengan tombol sebelumnya/berikutnya serta tombol tandai atau batalkan selesai.
- Progres belajar yang disimpan menggunakan `localStorage`, termasuk opsi reset progres.
- Kuis 10 soal pilihan ganda dengan umpan balik, pembahasan, skor, ulasan jawaban, skor terbaik, dan percobaan ulang.
- Mode gelap/terang, navigasi aktif, menu ponsel, indikator progres membaca, notifikasi, dan tombol kembali ke atas.
- Bagian proyek akhir, petunjuk alur belajar, serta tiga rujukan eksternal dari UNESCO dan NIST.
- Layout responsif untuk laptop, tablet, dan ponsel; dukungan fokus keyboard dan pengurangan animasi sesuai preferensi perangkat.

## Struktur berkas

- `index.html` — struktur halaman dan teks antarmuka.
- `style.css` — desain visual, tema, animasi, dan tata letak responsif.
- `script.js` — data modul, data soal, pencarian/filter, progres, tema, dan logika kuis.
- `RUBRIK-PENILAIAN.md` — daftar periksa kesesuaian website dengan aspek penilaian.

## Tujuan pembelajaran

Setelah menggunakan website, peserta didik diharapkan dapat:

1. Menjelaskan konsep dasar, manfaat, dan keterbatasan Generative AI.
2. Menentukan kebutuhan pengguna sebelum merancang media pembelajaran.
3. Menyusun prompt yang jelas dan mengembangkan media dengan bantuan AI secara kritis.
4. Menjelaskan langkah implementasi, evaluasi, dan optimalisasi media.
5. Mengenali prinsip privasi, hak cipta, keadilan, transparansi, dan verifikasi hasil AI.

## Panduan demonstrasi saat presentasi

1. Tunjukkan desain beranda dan navigasi.
2. Buka bagian **Materi**, cari sebuah kata kunci, lalu buka salah satu modul.
3. Tandai modul selesai dan tunjukkan perubahan progres. Muat ulang halaman untuk memperlihatkan penyimpanan lokal.
4. Ubah tema gelap/terang dan tunjukkan tampilan pada layar kecil melalui mode responsif browser.
5. Jalankan kuis, pilih jawaban, baca umpan balik, selesaikan semua soal, dan perlihatkan nilai serta ulasan jawaban.
6. Akhiri dengan informasi proyek, sumber rujukan, dan catatan bahwa materi AI tetap harus diverifikasi.

## Catatan akademik

Isi website merupakan rangkuman pengantar dan bukan pengganti buku ajar atau penilaian guru. Periksa kembali kesesuaian materi dengan instruksi pengajar dan kurikulum sebelum dikumpulkan. Jangan memasukkan data pribadi atau informasi sensitif ke layanan AI tanpa izin dan perlindungan yang sesuai.
